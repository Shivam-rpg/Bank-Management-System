# 🏦 Bank Management System

A modern and secure **Bank Management System** built using **Python, Streamlit, PostgreSQL, and Neon Database**.

This project allows users to create bank accounts, login securely using PIN authentication, deposit and withdraw money, check balance, update account details, and view transaction history.

---

# 🚀 Features

✅ Create New Bank Account  
✅ Secure PIN Authentication (SHA-256 Hashed PINs)  
✅ Login System  
✅ Deposit Money  
✅ Withdraw Money  
✅ Check Account Balance  
✅ Transaction History / Audit Logs  
✅ Update Account Information  
✅ Change PIN  
✅ Delete Account  
✅ Responsive Streamlit UI  
✅ PostgreSQL Database Integration  
✅ Neon Cloud Database Support  
✅ Streamlit Cloud Deployment Support  

---

# 🛠️ Tech Stack

- **Frontend:** Streamlit
- **Backend:** Python
- **Database:** PostgreSQL
- **Cloud Database:** Neon PostgreSQL
- **Authentication:** SHA-256 PIN Hashing
